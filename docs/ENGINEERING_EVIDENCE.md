## How to evaluate a project

1. **Problem and constraints:** What operational or user problem is being solved?
2. **Architecture:** Which components own data, transactions, events and permissions?
3. **Failure behavior:** What happens on duplicate requests, timeouts, restarts and partial failures?
4. **Verification:** Which tests and CI checks are available, and how can they be reproduced?
5. **Operations:** What are the deployment requirements, logs, metrics and recovery procedures?
6. **Trade-offs:** Why was this architecture selected over simpler alternatives?
