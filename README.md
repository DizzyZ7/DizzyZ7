## About

I am a **Fullstack / Backend / Automation Developer** focused on building systems that remove manual work, connect services and turn product ideas into working MVPs.

My main strength is the intersection of **backend engineering, business operations and automation**: I analyze messy workflows, design clean architecture, build APIs and data models, connect external services, add background processing, package everything with Docker/CI and document the result so it can be maintained and scaled.

I work across **Python, FastAPI, PostgreSQL, Telegram Bot API, CRM/helpdesk integrations, Docker, GitHub Actions, RAG/AI support systems, monitoring, computer vision prototypes and E2E testing**. I also like animals a lot — especially **cats, dogs and horses**.
